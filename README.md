# ✂️ Smart Salon Tracker

A stunning, single-page web application for discovering nearby salons, booking appointments, and managing salon operations. Built with a beautiful dark neon glassmorphic design and zero external frameworks.

## ✨ Features

- **🔍 Discover**: Search and filter through salons by service, distance, rating, and price. 
- **🗺️ GPS Map View**: Interactive map (powered by Leaflet) showing salon locations, with a "Locate Me" feature to find the closest salon to you.
- **📅 Appointments**: Track upcoming, completed, and cancelled bookings. Full booking flow with service and staff selection.
- **👤 Customer Management**: Full CRM to manage customer profiles, visit history, and preferences.
- **👥 Staff Management**: Manage team members, their specialties, and their current availability status.
- **📊 Analytics Dashboard**: Real-time canvas charts showing revenue trends, service category breakdowns, and top performers.
- **💾 Local Storage**: All data persists in your browser's local storage.

## 💻 Tech Stack

- **Frontend**: Pure HTML5, CSS3, Vanilla JavaScript (No React, Vue, or build tools required)
- **Mapping**: [Leaflet.js](https://leafletjs.com/) with OpenStreetMap tiles
- **Design**: Custom CSS Variables, Glassmorphism, CSS Grid & Flexbox
- **Charts**: Custom HTML5 `<canvas>` rendering (No heavy chart libraries)

## 🚀 How to Run

Because this app uses no build tools or backend servers, running it is incredibly simple:

1. Clone this repository or download the files.
2. Double-click on `index.html` to open it in your default web browser.
3. The app is pre-seeded with demo data (salons, customers, staff, and appointments) so you can explore all features immediately.

## 🎨 Design System

The app utilizes a custom **Dark Neon Glassmorphism** aesthetic:
- **Base**: Deep dark purple/blue backgrounds (`#06060e`)
- **Accents**: Neon Cyan, Magenta, Purple, Green, and Orange
- **UI Elements**: Translucent frosted glass panels with subtle glow effects and smooth micro-animations.
